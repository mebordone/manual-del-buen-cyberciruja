# Guía de diagnóstico rápida — Cybercirujas

Esta guía acompaña el diagrama de flujo y sirve para realizar un **diagnóstico básico de computadoras** antes de una jornada de recuperación.

🎯 **Objetivo:**  
Detectar rápidamente si una computadora:
- Funciona correctamente
- Se puede recuperar con cambios simples (RAM, disco, fuente, periféricos)
- Requiere diagnóstico técnico más avanzado

---

## 🧰 1. Preparación

Antes de empezar:

- Conectar:
  - Energía
  - Monitor
  - Teclado y mouse
- Tener a mano:
  - Pendrive con Linux (live USB)
- Opcional:
  - Destornillador para abrir la PC

⚠️ Importante:
- Abrir la computadora **siempre apagada y desenchufada**

---

## ⚡ 2. Encendido inicial

Presionar botón de encendido.

### Verificar:
- ¿Se encienden luces (LED)?
- ¿Giran los ventiladores?

👉 Si **NO enciende**:
- Revisar cable de alimentación
- Revisar enchufe
- Posible problema de fuente

👉 Si **SÍ enciende**:
- Continuar

---

## 🖥️ 3. Video

### Verificar:
- ¿El monitor muestra imagen?

👉 Si **NO hay imagen**:
- Revisar cable de video
- Probar otro monitor si es posible

👉 Si **SÍ hay imagen**:
- Continuar

---

## 💻 4. Sistema operativo

### Verificar:
- ¿Arranca el sistema operativo?

👉 Si **SÍ arranca**:
- Probar:
  - Abrir navegador
  - Abrir documento
- Evaluar si es usable

👉 Si **NO arranca**:
- Arrancar con **pendrive (live USB)**

---

## 🔍 5. Prueba con live USB

### Verificar:
- ¿El sistema live funciona?
- ¿Se mueve el mouse?
- ¿No se cuelga?

👉 Si **funciona bien**:
- Probable problema de disco o sistema
- 👉 Solución típica: cambiar a SSD o reinstalar sistema

👉 Si **NO funciona**:
- Posible problema de:
  - RAM
  - Placa madre
  - Fuente

---

## 🧠 6. Chequeos simples (abrir la PC)

⚠️ Solo con la PC apagada y desenchufada

### Revisar:
- Mucho polvo → limpiar
- Cables sueltos → reconectar
- RAM mal colocada → sacar y volver a poner

### Pruebas:
- Reinsertar RAM (reseat)
- Probar con otro módulo si hay

---

## 🔧 7. Diagnóstico rápido (qué cambiar)

Marcar lo que corresponda:

- ☐ Fuente (no enciende / comportamiento raro)
- ☐ RAM (no arranca / errores / cuelgues)
- ☐ Disco (lento / no arranca / ruidos)
- ☐ Periféricos (teclado, mouse, monitor)

---

## ✅ 8. Clasificación final

Elegir una opción:

### 🟢 Recuperable (cambio simple)
- Funciona o casi funciona
- Solo necesita:
  - SSD
  - Más RAM
  - Fuente
  - Limpieza

### 🟡 Requiere diagnóstico avanzado
- No arranca ni con live USB
- Problemas raros o inconsistentes

### 🔴 No vale la pena
- Muy vieja (ej: Pentium 4, DDR1)
- Muy poca RAM (<2GB DDR2)
- Hardware obsoleto

---

## 📝 9. Registro (muy importante)

Anotar para cada máquina:

- ¿Enciende? (Sí/No)
- ¿Da video? (Sí/No)
- ¿Arranca sistema? (Sí/No)
- ¿Funciona live USB? (Sí/No)
- RAM (cantidad)
- Tipo de disco (HDD / SSD)
- Problemas detectados
- Clasificación final

---

## 💡 Consejos Cybercirujas

- Empezar siempre por lo más simple
- Limpiar mejora mucho el funcionamiento
- Cambiar HDD → SSD hace gran diferencia
- No forzar componentes
- Documentar todo

---

## 🚀 Objetivo final

Que los técnicos puedan:
- Saber qué máquinas recuperar
- Llevar los repuestos correctos
- Ahorrar tiempo en la jornada
